# lab-5
The provided text details an evaluation of 7 AI image-generation tools (ChatGPT, Ideogram, Gemini, Perplexity, Leonardo AI, Adobe Firefly, and DeepAI) using a single standardized prompt: creating a promotional landscape image of young travelers inside a modern airport without logos or text.

Although the input prompt remained constant, each tool was assigned a distinct business use case within aviation marketing—ranging from airline ads and social media campaigns to presentation backgrounds and loyalty program promotion.

Key Takeaways
Efficiency vs. Review: AI tools significantly speed up content creation for aviation communications, but human review is essential to check visual quality, brand alignment, accuracy, and unwanted artifacts before publication.

Versatility: A single prompt can yield outputs suited for multiple marketing channels depending on tool capabilities and context.
